# Bundled fonts

The app bundles static Latin subsets of DM Sans (400–700) and Plus Jakarta Sans
(400–800) from Fontsource 5.2.6. Both families are distributed under the SIL
Open Font License 1.1; their original license notices are included here.

- https://github.com/fontsource/font-files/tree/main/fonts/google/dm-sans
- https://github.com/fontsource/font-files/tree/main/fonts/google/plus-jakarta-sans
- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/plusjakartasans
